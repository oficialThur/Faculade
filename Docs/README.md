# Trabalho POO 

Você foi designado para desenvolver o sistema de uma Faculdade. O sistema será responsável por gerenciar alunos da faculdade e seus cursos e disciplinas!
___

**Premissas**

a) Desenvolva um Menu que permita controlar seu sistema (exemplo abaixo);

b) Desenvolva cada uma das funcionalidades dos Submenus (exemplo abaixo);

c) Um ALUNO deve possuir um CURSO (e pelo menos os dados adicionais como
nome, idade e matrícula);

    i) Ao cadastrar um aluno, deve ser escolhido um dos cursos existentes
    ii) Ao mostrar os dados do aluno, o sistema deve mostrar seu curso e todas as disciplinas

d) Um CURSO deve pussuir pelo menos 1 ou mais DISCIPLINAS (e pelo menos os dados adicionais como nome do curso, turno e código do curso);

e) Uma DISCIPLINA deve possuir, pelo menos código da disciplina, nome,carga horária;

    i) Ao cadastrar uma disciplina, esta deve pertencer a um curso específico

f) Lembre-se de só sair do programa ao escolher a opção SAIR;

g) Você deverá utilizar LISTAS para salvar seus objetos

h) Organize seu sistema em classes de Menu, Submenu, Controller, Model, DAO, etc.

i) Seu sistema deverá utilizar Banco de dados

j) Você deverá apresentar seu sistema e ser capaz de explicar trechos de
códigos, princípios de desenvolvimento e padrões utilizados.
Questionamentos sobre estratégias de POO serão realizadas durante a
apresentação. Esteja preparado!

## Atividade 1
Crie um diagrama de classes que atenda a abstração apresentada acima.

## Atividade 2
Implemente seu sistema através da linguagem Java com POO, conforme as
informações do Menu abaixo:

### 01-Crie um sistema com um MENU com as seguintes opções:
  
  1-Gerenciar ALUNOS
  2-Gerenciar DISCIPLINAS
  3-Gerenciar CURSOS
  4-SAIR

### 02-Crie um SUBMENU com as seguintes opções para a opção 1:
  
  1-Cadastrar ALUNO
  2-Consultar ALUNO
  3-Remover ALUNO
  4-Atualizar ALUNO
  5-Voltar ao MENU INICIAL

### 03-Crie um SUBMENU com as seguintes opções para a opção 2:
  
  1-Cadastrar DISCIPLINA
  2-Consultar DISCIPLINA
  3-Remover DISCIPLINA
  4-Atualizar DISCIPLINA
  5-Voltar ao MENU INICIAL

### 04-Crie um SUBMENU com as seguintes opções para a opção 3:
  
  1-Cadastrar CURSO
  2-Consultar CURSO
  3-Remover CURSO
  4-Atualizar CURSO
  5-Voltar ao MENU INICIAL
